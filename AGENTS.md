# Project continuity

For research work in a new conversation, read [MEMORY.md](MEMORY.md), then use
[the current project state](reports/00_project_state.md) and
[the handoff](reports/NEXT_SESSION_HANDOFF.md) for the relevant details.
Historical reports retain their original methods; they do not override the
current experiment declaration or the subsequent corrections.

Keep certified completed experiments reproducible. Read their source/hash records
before changing shared numerical code; use a new experiment identity for changed
methods. Keep local datasets, predictions and checkpoints under the existing
ignored paths. Commit the declared reports and compressed evaluation results.

Use plain language with a short findings summary alongside the full result tables.
For long runs, preserve the completion/error watcher and report actual status.
The latest handoff records which stages are complete and which remain proposals;
continue according to the user's current instructions.
